# Stage 1 - Capa de datos del buscador

Primera fase del proyecto de Big Data (ULPGC): descargar libros de Project Gutenberg, guardarlos en un
datalake y construir los datamarts (metadatos + índice invertido), comparando varias estructuras en
tres lenguajes.

Las reglas comunes a las tres implementaciones están en [spec/pipeline_spec.md](spec/pipeline_spec.md).
